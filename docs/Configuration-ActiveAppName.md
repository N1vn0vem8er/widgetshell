# Active App Name

The Active App Name widget displays the title of an active app. 
This widget is compositor-dependent and will not work with unsupported compositors.

The appearance of this widget can be customized using `ActiveAppNameComponent`. For example:

```css
ActiveAppNameComponent {
    background-color: #38427f;
}
```

In order to add Active App Name to the bar use:

```json
{
    "component": "activeappname"
}
```
