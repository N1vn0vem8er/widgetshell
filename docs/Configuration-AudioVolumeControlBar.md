# Audio Volume Control

The Audio Volume Control displays current volume and allows for changing it using scroll.

The appearance of this widget can be customized using `AudioVolumeControlBarComponent`. For example:

```css
AudioVolumeControlBarComponent {
    background-color: #38427f;
}
```

In order to add Audio Volume Control to the bar use:

```json
{
    "component": "audiocontrol"
}
```
