# Bar

Bar can display time, date, workspaces, opened apps and more. It is located at the top of the screen and 
its location cannot be changed. Height of bar can be changed by setting `height` in `Bar` in `widgetshell.conf` file.

Bar layout can be configured with `bar.json` file. The list of all avaliable widgets that can be placed
in the bar can be found [here](Configuration.md#Bar).
