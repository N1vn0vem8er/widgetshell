# Cpu Usage Chart

The Cpu Usage chart widget displays current cpu usage chart in the control menu.

The appearance of this widget can be customized using `CpuUsageChartComponent`. For example:

```css
CpuUsageChartComponent {
    background-color: #38427f;
}
```

In order to add Cpu Usage to the bar use:

```json
{
    "component": "cpuusagechart"
}
```
