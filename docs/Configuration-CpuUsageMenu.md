# Cpu Usage

The Cpu Usage widget displays current cpu usage graph in the control menu.

The appearance of this widget can be customized using `CpuUsageMenuComponent`. For example:

```css
CpuUsageMenuComponent {
    background-color: #38427f;
}
```

In order to add Cpu Usage to the bar use:

```json
{
    "component": "cpuusagemenu"
}
```
