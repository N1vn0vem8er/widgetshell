# Memory Usage Chart

The Memory Usage chart widget displays current memory usage chart in the control menu.

The appearance of this widget can be customized using `MemoryUsageChartComponent`. For example:

```css
MemoryUsageChartComponent {
    background-color: #38427f;
}
```

In order to add Memory Usage to the bar use:

```json
{
    "component": "memoryusagechart"
}
```
