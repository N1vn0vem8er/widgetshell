# Memory Usage

The Memory Usage widget displays current memory usage graph in the control menu.

The appearance of this widget can be customized using `MemoryUsageMenuComponent`. For example:

```css
MemoryUsageMenuComponent {
    background-color: #38427f;
}
```

In order to add Memory Usage to the bar use:

```json
{
    "component": "memoryusagemenu"
}
```
